# Aplikasi Pelaporan Fasilitas Kampus - Java NetBeans

Desktop application for reporting damaged campus facilities at UMSU. Built with Java Swing & MySQL.

## Features
- Login System
- Tambah Laporan (with photo upload)
- List & Status Tracking (Pending / Fixed)
- Admin Dashboard

## Tech Stack
- Java (NetBeans IDE)
- Java Swing (GUI)
- MySQL (kampus.sql)
- JDBC, OOP Concept

## How to Run
1. Import kampus.sql to MySQL
2. Open project in NetBeans
3. Run Main.java
